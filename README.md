# lda-reviews
В проекте проведён анализ отзывов потребителей с помощью тематического моделирования (LDA). В результате были выделены темы, волнующие клиентов, и определены ключевые точки роста для бизнеса.

## Описание проекта

- Исследованы отзывы покупателей трёх крупнейших косметических сетей
- Проведена очистка текста: удаление шумов, токенизация, лемматизация, устранение опечаток с использованием расстояния Левенштейна
- Для каждой сети обучены LDA-модели с подбором оптимального числа тем
- Полученные результаты визуализированы и обобщены в итоговом отчёте

##  Данные

Оригинальные данные не публикуются по причинам приватности.  
Однако воспроизвести сбор можно самостоятельно: в репозитории  
[`revenue-reputation-analysis`] в папке [`scripts`](https://github.com/mltsvnn/revenue-reputation-analysis/tree/main/scripts)  
доступны шаблоны парсеров для получения отзывов с публичных источников.

- Jupyter Notebook
- Библиотеки:
  - `pandas`
  - `nltk`

  - `gensim` (реализация LDA)

  - `tqdm`
